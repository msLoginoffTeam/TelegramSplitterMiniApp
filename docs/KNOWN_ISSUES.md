# Telegram Splitter Mini App — журнал проблем и решений

Обновлено: 2026-08-07. Статусы: `open`, `planned`, `fixed`, `won't fix`.

| ID     | Приоритет | Статус  | Область         | Проблема / решение                                                                                                                                                                                                                                                                                                                                                                             |
| ------ | --------- | ------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FE-001 | P0        | fixed   | Foundation      | Foundation реализован: React 19, Vite 8, TypeScript 7, Yarn 4, Axios, TanStack Query, React Router, FSD-lite, SCSS Modules, generated API artifacts и quality CI. Product UI намеренно не входит в этот этап.                                                                                                                                                                                  |
| FE-002 | P0        | fixed   | Integration     | Axios boundary передаёт Telegram `initData` в `X-Telegram-Init-Data`; browser-mode использует только явный `VITE_DEV_TELEGRAM_USER_ID` для локального Development backend и не подделывает production auth.                                                                                                                                                                                    |
| FE-003 | P1        | fixed   | API client      | Актуальный Swagger получен из локального backend, snapshot и output `react-query-swagger` сгенерированы. `react-query-swagger` 15.13.2 оставляет unused imports/locals, поэтому `noUnusedLocals`/`noUnusedParameters` не блокируют typecheck. Скрипт генерации автоматически убирает trailing whitespace; generated code вручную не редактируется.                                             |
| FE-004 | P1        | fixed   | Environments    | Реализованы Telegram/browser platform adapters: browser mode не подделывает initData, Telegram SDK изолирован в `shared/platform/telegram`, initialization проверен на idempotence.                                                                                                                                                                                                            |
| FE-005 | P1        | fixed   | UX              | Добавлен широкий navigation skeleton: список/создание групп, дашборд и разделы группы. Данные, формы и split flow намеренно не реализованы; они будут следующими независимыми шагами.                                                                                                                                                                                                          |
| FE-006 | P2        | fixed   | Docker          | Frontend имеет независимый Compose и production-like Nginx image. В контейнере `/api` проксируется в `API_UPSTREAM`; в Vite dev server тот же путь проксируется в `VITE_DEV_API_PROXY_TARGET`. Backend и БД намеренно не дублируются в этом репозитории.                                                                                                                                       |
| FE-007 | P1        | fixed   | Toolchain       | По запросу пользователя берём актуальный TypeScript 7.0.x и Oxlint вместо `typescript-eslint`, у которого peer range пока ограничен `<6.1`. Oxlint покрывает TypeScript/React lint и no-restricted-imports для архитектурных границ.                                                                                                                                                           |
| FE-008 | P1        | fixed   | React           | React 19 собран и протестирован с выбранным стеком. `@telegram-apps/telegram-ui` не добавлен из-за ограниченных React 18 peer dependencies.                                                                                                                                                                                                                                                    |
| FE-009 | P1        | fixed   | API artifacts   | Принято решение коммитить `openapi/backend.json` и `src/shared/api/generated/`; локальная разработка перегенерирует оба артефакта, CI позднее проверяет drift.                                                                                                                                                                                                                                 |
| FE-010 | P1        | open    | Deployment      | Независимые Compose-файлы намеренно не создают общую Docker network. Перед VPS нужно согласовать домены и reverse proxy: frontend передаёт `/api/*` в явный `API_UPSTREAM`, который в production должен быть HTTPS origin API.                                                                                                                                                                 |
| FE-011 | P1        | fixed   | Group dashboard | Экран группы показывает реальные название, балансы участников, список трат и доступное действие создания траты по permission.                                                                                                                                                                                                                                                                  |
| FE-012 | P1        | planned | Expense flow    | Полноэкранная mobile-first форма создания траты готова: ручные доли и equal split с остатком в долю плательщика. Редактирование и удаление остаются следующим шагом.                                                                                                                                                                                                                           |
| FE-013 | P1        | fixed   | Invites         | Invite flow создаёт expiring Telegram `startapp` ссылку и принимает её внутри Mini App. Username бота получается backend через `getMe`; `BotUsername` нужен только как необязательный local override.                                                                                                                                                                                          |
| FE-014 | P1        | open    | Telegram chat   | Bot API не позволяет получить полный список исторических участников чата. Нужен согласованный fallback: администраторы/инициатор при создании, затем события новых участников и активность пользователей; не подключать MTProto без отдельного решения.                                                                                                                                        |
| FE-015 | P0        | fixed   | Invite launch   | Холодный запуск открывал `/groups`: индексный redirect `/ → /groups` состязался с redirect на приглашение, а защита от мерцания затем считала token обработанным. Root router теперь приоритетно выбирает `/invite/<token>`; для Telegram bridge оставлены официальный `telegram-web-app.js`, fallback чтения start-param и короткая повторная проверка. Подтверждено вручную на iOS Telegram. |
