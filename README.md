# Telegram Splitter Mini App

Frontend for a Telegram Mini App that tracks shared expenses, payments, balances and optimized settlement transfers.

## Status

Repository foundation. Product and API contracts are being stabilized before the React application scaffold is added.

## Planned stack

- React + TypeScript
- Vite
- TanStack Query
- OpenAPI-generated API client
- Telegram Mini Apps SDK integration
- Docker for local and production builds

Exact UI, validation and testing libraries will be selected during the frontend foundation phase.
